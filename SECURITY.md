# Security Policy

## Reporting a vulnerability

请不要在公开 Issue 中上传原始 GNSS/IMU 数据、个人报告、参考轨迹或访问凭据。安全问题可通过 GitHub Security Advisories 私密报告：

Please do not upload raw GNSS/IMU data, personal reports, reference trajectories, or credentials to public issues. Use the repository's private GitHub Security Advisory channel:

https://github.com/thisisac/gnss-ins/security/advisories/new

If private advisories are unavailable, open a minimal public issue without sensitive attachments and request a private channel.
