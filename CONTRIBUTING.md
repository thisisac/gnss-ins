# Contributing

感谢你对 GNSS/INS 项目的关注。欢迎通过 GitHub Issue 报告问题、提出改进建议，或提交 Pull Request。

Please use GitHub Issues for bug reports and feature requests. For code changes, create a focused branch, explain the navigation-model impact, and open a Pull Request against `main`.

提交前请确认：

- 未包含原始 GNSS/IMU 数据、个人报告、私有参考轨迹或本地绝对路径；
- C++ 修改可以在 Visual Studio C++17 环境中构建；
- Python/MATLAB 工具的输入输出路径仍遵循文档；
- 结果变化已在 Pull Request 中说明；
- 新增文件使用合适的许可证。

Before submitting, check that no raw data, personal documents, private references, or machine-specific paths are included. Describe numerical or algorithmic behavior changes in the Pull Request.
